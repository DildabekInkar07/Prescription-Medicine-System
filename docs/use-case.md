# Use Case – жүйені пайдалану сценарийлері

## Пациент
- Жүйеге кіреді
- Рецептін көреді
- Қажетті дәріні іздейді
- Дәріханалардағы дәрі қорын көреді
- Дәріхананы таңдайды
- Дәріні брондайды
- QR-код алады
- Дәріні қабылдау кестесін көреді
- Ескертулер алады

## Дәрігер
- Жүйеге кіреді
- Пациент туралы ақпаратты көреді
- Рецепт жазады
- Рецептті өзгертеді
- Қабылдау тәртібі бұзылған жағдайда хабарлама алады

## Фармацевт
- Жүйеге кіреді
- Рецептті тексереді
- Броньды тексереді
- QR-кодты растайды
- Дәріні дайындайды
- Дәріні пациентке береді

## Әкімші
- Пайдаланушыларды басқарады
- Дәріханалар туралы ақпаратты басқарады
- Жүйенің жұмысын бақылайды
