# Prescription Medicine System

## Жоба туралы
Бұл ақпараттық жүйе пациенттің қолындағы рецепт бойынша қажетті дәріні іздеу,
дәріхананы таңдау, дәріні брондау және дәріні қабылдау уақытын бақылауға арналған.

## Негізгі пайдаланушылар
- Пациент
- Дәрігер
- Фармацевт
- Әкімші

## Негізгі функциялар
- Рецепт мәліметтерін көру
- Қажетті дәріні іздеу
- Дәріханалардағы дәрі қорын тексеру
- Дәріхананы таңдау
- Дәріні брондау
- QR-код алу
- Дәріні қабылдау кестесін бақылау
- Ескерту хабарламаларын алу

## Жобаның мақсаты
Рецепт бойынша дәріні іздеу, брондау және қабылдауды бақылау процесін
автоматтандыру.
